An automated configuration management push updated DNS forwarder addresses on both prod-dns-01 and prod-dns-02 simultaneously. The new forwarder IPs (10.0.99.53 and 10.0.99.54) were incorrect — pointing to a decommissioned network segment. Internal DNS queries continued working from cache, but all external domain resolution failed as cached entries expired. This caused cascading failures across all services dependent on external APIs (Stripe, AWS SQS, SendGrid).
