The wildcard TLS certificate for *.example.com expired at midnight on April 20. Automatic renewal via certbot had been failing for 7 days because the CloudFlare API token used for DNS-01 challenge validation had expired. Certbot logged errors on every retry attempt but no alerting was configured for renewal failures. With HSTS headers active, browsers could not fall back to HTTP, causing a complete outage for all HTTPS traffic including the web portal and API endpoints.
